# Чат для Telegram через GREEN-API

Адаптивный веб-клиент на React и TypeScript для отправки и получения текстовых сообщений Telegram через сервис GREEN-API. Внешний вид основан на лаконичной компоновке веб-версии MAX, но не использует её логотипы или закрытые графические материалы.

## Возможности

- подключение по `idInstance` и `apiTokenInstance`;
- проверка авторизации инстанса перед входом;
- создание нескольких личных чатов по номеру телефона;
- отправка текстовых сообщений с оптимистичным отображением статуса;
- повторная отправка сообщения после ошибки;
- получение ответов через очередь уведомлений GREEN-API;
- автоматическое создание чата для нового входящего собеседника;
- сохранение текущей сессии и переписки в `sessionStorage`;
- адаптивные desktop- и mobile-интерфейсы;
- доступная навигация с клавиатуры.

## Технологии

- React 19;
- TypeScript в строгом режиме;
- Vite;
- CSS Modules;
- Oxlint.

Приложение не использует дополнительный менеджер состояния и не требует собственного сервера.

## Требования

- Node.js 20.19+ или 22.12+;
- npm;
- созданный и оплаченный либо тестовый Telegram-инстанс GREEN-API.

## Локальный запуск

1. Откройте терминал и перейдите в папку проекта:

   ```bash
   cd C:\Projects\chat-online
   ```

2. Установите зависимости:

   ```bash
   npm install
   ```

3. Запустите приложение в режиме разработки:

   ```bash
   npm run dev
   ```

4. Откройте в браузере [http://127.0.0.1:3000](http://127.0.0.1:3000).

Сервер разработки автоматически обновляет страницу после изменений в исходном коде. Для его остановки нажмите `Ctrl+C` в терминале.

Чтобы локально проверить production-версию приложения, выполните:

```bash
npm run build
npm run preview
```

Команда `npm run build` создаст оптимизированную сборку в папке `dist`, а `npm run preview` запустит её локальный предпросмотр. Адрес предпросмотра будет указан в терминале.

## Подготовка GREEN-API

1. Зарегистрируйтесь в [личном кабинете GREEN-API](https://console.green-api.com/).
2. Создайте инстанс для Telegram.
3. Авторизуйте инстанс рекомендуемым способом из личного кабинета.
4. В настройках включите получение уведомлений о входящих сообщениях и файлах (`incomingWebhook`).
5. Для получения через HTTP API оставьте поле `webhookUrl` пустым.
6. Скопируйте `idInstance` и `apiTokenInstance` в форму подключения приложения.

Подробнее: [подготовка Telegram-инстанса](https://green-api.com/telegram/docs/before-start/) и [получение уведомлений через HTTP API](https://green-api.com/telegram/docs/api/receiving/technology-http-api/).

## Использование

После подключения нажмите «Новый чат» и введите номер получателя в международном формате. Допустимы пробелы, круглые скобки, дефисы и ведущий `+`, например:

```text
+7 999 123-45-67
```

После очистки форматирования номер должен содержать от 7 до 15 цифр. Сообщение отправляется клавишей `Enter`; сочетание `Shift+Enter` добавляет новую строку.

## Безопасность

Это демонстрационное клиентское приложение. Токен GREEN-API передаётся из браузера непосредственно сервису и потому доступен в инструментах разработчика.

- Реквизиты не записываются в исходный код и не отправляются сторонним сервисам.
- Сессия хранится только в `sessionStorage` и удаляется при закрытии вкладки либо нажатии кнопки выхода.
- Не добавляйте реальные токены в Git, `.env` или README.
- Для production-системы запросы следует выполнять через собственный сервер, который скрывает токен и реализует пользовательскую авторизацию.

## Ограничения

- Поддерживаются только личные текстовые сообщения.
- Группы, медиафайлы, реакции и голосовые сообщения игнорируются.
- История ограничена сообщениями текущей сессии; журналы GREEN-API не загружаются.
- Успешный ответ `SendMessage` означает постановку сообщения в очередь, а не гарантированную доставку получателю.
- GREEN-API Telegram находится в beta-версии, поэтому контракт сервиса может измениться.
